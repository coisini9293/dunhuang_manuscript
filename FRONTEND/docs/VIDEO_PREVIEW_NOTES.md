# 视频预览说明

## 当前状态

本阶段尝试按 README 要求准备 45–90 秒的真实交互预览，但当前浏览器控制能力只提供页面导航、点击、输入和截图接口，没有可保存的连续浏览器视频流或屏幕录制接口。

因此本阶段没有用静态截图拼接成“假视频”，也没有生成一个会误导为真实操作录屏的 `site-preview.mp4`。交互证据以 `screenshots/` 中的静态截图、独立预览页和页面内可操作控件为准。

## 建议的真实录制顺序

若在本机浏览器中录制，可按下列顺序完成一段约 70 秒的真实操作：

1. 0–10 秒：首页横向首屏，展示原有文字、右侧主视觉和中部羽化；切换一次背景图或羽化强度。
2. 10–20 秒：向下滚动到“敦煌历史”，展示中轴线与左右交替节点；点击一个节点进入详情。
3. 20–30 秒：返回首页，进入“同源识别与智能缀合”，展示 A/B 工作台、上传、旋转、交换和回放入口。
4. 30–45 秒：进入“古卷证据约束修复”，依次展示证据探索、逐项裁决、批准区域和结果查看器。
5. 45–58 秒：点击“约束修复回放”或专业结果查看区域，说明工程结果与人工/学术判断的边界。
6. 58–68 秒：进入“关于我们”，点击六步流程卡片，展示“真实内容必须能回到出处”。
7. 68–75 秒：缩窄窗口展示移动端首页或历史页的纵向阅读方式。

## 防止误导的录制要求

- 必须录到真实点击和滚动，不要将生成的历史示意图说成文物证据。
- 工作台操作应保留正式项目的真实字段、replay 来源和接口状态；离线时应明确显示 replay/离线状态。
- 不要把工程 PASS、候选文字或视觉结果表述为自动完成的学术结论。
